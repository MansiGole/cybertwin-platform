# CyberTwin Platform

> Interactive cyber-risk simulation platform built for Smart India Hackathon (SIH).

## Project Overview
CyberTwin is an interactive simulation system designed to model, analyze, and mitigate cyber-risk scenarios. It integrates real-time telemetry, machine learning threat detection models, and blockchain verification for unalterable audit trails.

---

## My Contributions & Architecture Role
As part of the SIH team, I engineered and architected the **Backend & Simulation Layer** (`/cybertwin-platform/backend`):

* **Simulation Engine:** Developed core logic to execute and evaluate simulated cyber attack paths.
* **REST API Layer:** Built API endpoints for simulation controls, telemetry ingestion, and device/asset status monitoring.
* **Risk Analytics Pipeline:** Implemented data processing endpoints to score threat vectors and feed dashboard KPIs.
* **Blockchain Audit Integration:** Integrated cryptographic verification to ensure tamper-proof audit trails for simulation events.
* **Database & Migrations:** Configured schema models and persistence handling for simulation history.
